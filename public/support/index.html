Questions fréquentes

Faut-il un compte ? Non. Vos données restent sur votre appareil.

L'app fonctionne-t-elle hors ligne ? Oui, une fois installée.

Comment effacer mes données ? Désinstallez l'app (sur le web : effacez les données du site dans votre navigateur).

Version web : https://mohamadalhabib92.github.io/zikru/ — sur iPhone ou iPad, ouvrez-la dans Safari puis Partager → « Sur l'écran d'accueil ».
